# Challenge Criptografia

## Problema

1. A flag foi cifrada com **ROT13**
2. O resultado foi convertido para **Hexadecimal**
3. A string hexadecimal foi **invertida**
4. A string invertida foi cifrada em **Base64**

O resultado final é:

```text
YTBkMGQ3NjMyMzAzMjNmNTM2YTcyNjA3YTdjNjY2Yjc0N2U2OTczNw==
```

Decodifique e encontre a flag original.

---

## Resposta

```text
flag{symcomp_2026}
```

---

## Solução

1. Decodificar Base64
https://www.base64decode.org/

2. Inverter a string
https://textreverse.net/

3. Converter Hexadecimal para texto
https://www.duplichecker.com/hex-to-text.php

4. Aplicar ROT13
https://rot13.com/
