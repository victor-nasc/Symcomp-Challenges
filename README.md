# Symcomp-Challenges
This repository houses some codes to solve all symcomp-challenges during Computer Science Week 2025

The Answers are in this [docs](https://docs.google.com/document/d/1Z5QQnKvUHKX-dfY2qBqkZI47jOoe_8eH7-fuzekCm3g/edit?usp=sharing)

## Setup

Install [uv](https://docs.astral.sh/uv/getting-started/installation/):
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Install dependencies and verify the environment:
```bash
uv sync
uv run python main.py
```
